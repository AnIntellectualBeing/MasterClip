# Installing MasterClip on Windows

Download the installer from [official releases](https://github.com/AnIntellectualBeing/MasterClip/releases). Install it, then open MasterClip from the Start menu. Python and FFmpeg are bundled.

This release is unsigned. If Windows shows **Windows protected your PC**, confirm the download came from the official release or company page. If you trust it and the option is available, choose **More info → Run anyway**.

Some managed PCs and Smart App Control configurations block unsigned software without offering that option. Contact **anintellectualcompany.contact@gmail.com** with a screenshot of the exact message.

Inside the app, open **Help** for recording, posting, quality and troubleshooting instructions. Keep MasterClip and the PC running for continuous clipping and retries. Posts already scheduled with Zernio can publish after the app closes.
